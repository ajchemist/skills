# ajchemist/skills

Agent skills for ajchemist's repositories.

```sh
bunx skills add ajchemist/skills
```

| Skill | What it does |
|---|---|
| `approved-gate` | Installs the approved-issue gate (no code without an `approved` issue; AI co-author trailers blocked) through the reusable workflows in [ajchemist/.github](https://github.com/ajchemist/.github). |
